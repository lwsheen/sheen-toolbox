起重链条安全检查表

使用说明

  • 本表适用于 G80 / G100 级起重链条、吊链及配套索具的日常、定期及专项安全检查。
  • 检查分三态判定：正常（符合要求）、注意（异常但未达报废，需观察/记录）、报废 / 不合格（达到 GB/T 20946-2007 报废指标，立即停用）。
  • 检查等级：日常检查（每次使用前，重点第 1、4、5、9 项）、定期检查（月度/季度，须第 1、2 项卡尺精密测量并对比原始记录）、专项检查（发生过猛烈冲击、过载、坠落后，必做第 2 项伸长测量，建议磁粉探伤 MT）。

安全要领速记（1、4、6 三点绝对红线）

  • 量长度：5 个环的总长，比原始 P5 拉长了 5%，报废！
  • 看焊缝：焊口裂了或脱焊了，报废！
  • 防冲击：链条绝对不能打结、扭曲受力，瞬间冲击极易直接崩断伤人。
安全提示：达到任一项报废指标，须立即停止使用；报废链条必须用切割机切断破坏，严禁剪短当短链在小负荷下使用、严禁流入二手市场；G80 / G100 链条严禁私自电焊修补或气焊烘烤，高温会直接破坏其热处理性能。

检查等级与最终结论（GB/T 20946-2007）

检查等级说明
日常检查
（每次使用前）		重点看第 1、4、5、9 项：有无断裂、变形、打结。
定期检查
（月度 / 季度）		必须严格进行第 1、2 项的卡尺精密测量，并对比原始验收记录。
专项检查
（冲击 / 过载 / 坠落事故后）		无论外观如何，必须进行伸长测量（第 2 项），并强烈建议进行磁粉探伤（MT）检查内部微裂纹。

处置措施

1. 报废的链条必须用切割机切断破坏，不可将报废长链剪断当成短链在小负荷下使用。
2. G80 / G100 级链条严禁私自电焊修补、气焊烘烤，高温会直接破坏其热处理性能。
