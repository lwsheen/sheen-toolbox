OSHA 可记录事故判断助手

依据美国 OSHA 29 CFR Part 1904《职业伤害与疾病的记录与报告》（现行 eCFR 版），按工作相关性 → 新病例 → 特殊条款 → 一般记录标准 → 急救清单例外的完整判定链，逐步判断一起职业伤害/疾病是否需要记入 OSHA 300 日志；并在结论页同步给出 NM / FA / MTI / RWC / LTA / FAT 的集团 HSE 绩效口径。

第 1 步

判定链

    使用说明

    • 按顺序回答问题，每一步会标注对应的 29 CFR 1904 条款；到达结论后可打印判定结果与判定链留存。
    • OSHA 规则要点：可记录 = 与工作相关的新病例，且符合一般记录标准之一（死亡 / 离岗 / 限制工作或调岗 / 超出急救的医疗处理 / 意识丧失 / 医生诊断的重大情形），或命中特殊条款（针刺伤、医学移除、标准听力损失、肺结核）。
    • 判定为可记录后，须在 7 个日历日内 填写 300 日志及 301 表（或州计划认可的等价表），记录保留 5 年；每年 2/1–4/30 提交 300A 汇总公示。
    • 结论页同时给出 集团 HSE 口径：FAT 死亡 → LTA 损失工时 → RWC 限工转岗 → MTI 医疗处理伤害 → FA 急救 → NM 险兆。OSHA 300 记录义务与集团口径是两套独立判定，同一份事实必须分别判、分别报——切勿用一套结论直接覆盖另一套。
    • 本工具基于联邦 OSHA（Federal OSHA）规则；州计划（State Plan，如加州 Cal/OSHA 等）可能有附加或更严格的记录要求，最终判定请以 OSHA 官方文本及企业 EHS 专业人员意见为准。

    免责声明：本工具依据公开国家标准、行业规范及官方文件整理，仅供参考与内部初步筛查之用，不构成任何专业法律、安全或工程意见。实际合规判定请以最新官方发布文本及具备资质的专业机构评估为准。使用者应自行核实相关标准的现行有效性。
