结构示意
临空高度 ≥1200 时，敞开边缘应设防护栏杆
相邻设施可能垮塌/不能起防护作用时，该处敞开边缘应设防护栏杆
防护栏杆应设置踢脚板（边缘结构/斜梯梯梁起踢脚板作用除外）
顶部横杆：任意位置方向集中活荷载 ≥0.89kN；均布 ≥0.70kN/m；挠度 相邻立柱间距 1/250
中间横杆 / 中间立杆 / 底部横杆：各自单独承受集中活荷载 ≥0.22kN；挠度 跨度 1/200
立柱及柱底连接：承受上述传递荷载；顶部位移 ≤30mm
结构形式（二选一）：
① 顶部横杆 + 中间横杆 + 立柱
② 顶部横杆 + 中间立杆 + 底部横杆 + 立柱
高度（临空 <2m）：≥900
高度（2m≤临空<20m）：≥1050
高度（临空 ≥20m）：≥1200
高度为平台/工作面上表面 → 顶部横杆顶面垂直高度（斜梯为踏板上表面 → 顶部横杆顶面）
立柱间距 ≤1000
立柱壁厚（管材）≥3.0mm
立柱壁厚（角型/T型）≥5mm
立柱壁厚（板材）≥6mm
扶手圆管直径 30~50；非圆形外接圆 ≤57，圆角半径 ≥3
扶手管材壁厚 ≥2.0mm
扶手间断净空（未倒圆）50~120；（倒圆）50~80，倒圆半径 ≤200
扶手外侧预留间隙 ≥75
扶手末端不应有造成伤害的突出物
中间横杆：顶部横杆下方至少一道；与上下构件竖向净距 ≤500
中间立杆：与相邻立杆/立柱水平净距 ≤180
踢脚板顶部在平台/工作面之上高度 ≥100
踢脚板底部距离平台/工作面间隙 ≤10（无排水可不留）
