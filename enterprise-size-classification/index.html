企业规模划分查询

依据国家统计局《统计上大中小微型企业划分办法》及 GB/T 4754-2017，按行业与三项指标判定企业规模（大型 / 中型 / 小型 / 微型）。

参数输入

指标您输入大型下限中型区间小型区间微型上限达标

划分规则说明

  • 大型、中型、小型：须同时满足所列指标的下限，否则下划一档。
  • 微型：只须满足所列指标中的任意一项即可认定为微型。
  • 行业范围以《国民经济行业分类》（GB/T 4754-2017）为准；带 * 的行业为组合类别（如工业含采矿业、制造业等）。
  • 从业人员：期末从业人员数，无则采用全年平均人数。
  • 营业收入：设置主营业务收入指标的行业用主营业务收入；农、林、牧、渔业用营业总收入；限额以下批零住餐分别用商品销售额 / 营业额代替。
  • 资产总额：采用资产总计代替。

数据口径：国家统计局《统计上大中小微型企业划分办法》（国统字〔2017〕213号）及 GB/T 4754-2017。本工具仅作参考，正式认定以统计/行业主管部门口径为准。
