HAZID 危险源识别工作表

多专业团队围绕通用危险源类别头脑风暴，广泛识别潜在危险源并给出初步风险与后续分析建议（AQ/T 3033-2022 7.2.2 的五类引导已内置为下拉选项）。

#危险源类别引导问题 / 识别线索潜在危险源初步风险后续分析建议
HAZID 五类危险源引导（AQ/T 3033-2022 7.2.2）
类别引导要点
化学品危险化学品种类、特性、数量、浓度（含量）、物料禁配性、所在工艺单元及状态（温度、压力、相态）
工艺过程危险源可能导致泄漏、爆炸、火灾、中毒事故的危险源
作业人员危险因素粉尘、窒息、腐蚀、噪声、高温、低温、振动、坠落、机械伤害、放射性辐射等
外部 / 环境危险源建设项目所在地自然灾害、极端恶劣天气、人为破坏、周边设施等

What-If 假设分析工作表

以「如果……会怎样？」结构化提问识别非正常工况及其后果与应对，适合操作审查、设计审查与变更前快速筛查，可与检查表或其他方法联用。

#「如果…会怎样？」可能后果现有防护建议措施责任人 / 期限
模块二 · 详细设计阶段：查细节依据：GB/T 35320-2017 · GB/T 7826-2012

对工艺过程用 HAZOP 做引导词偏差分析，对设备 / 电气 / 仪控用 FMEA 做自下而上的失效模式分析，把早期识别的危险源落到具体节点与组件层面。

HAZOP 引导词偏差工作表

选择工艺参数与引导词，偏差自动组合（如「流量 + 无 → 无流量」）；逐项分析原因、后果与现有措施，识别缺口并跟踪建议闭环。

FMEA 失效模式与影响工作表

从单个组件 / 工序的失效模式入手评估其对上一层系统的影响。RPN = S × O × D 自动计算并排序；严重度 S ≥ 9 时无论 RPN 高低均须处理。

#组件 / 工序失效模式失效原因影响SODRPN判定改进措施
S / O / D 评分标准速查（1–10 分制）
分制高端（9–10）中段（4–6）低端（1–3）
S 严重度安全 / 法规风险，无预警失效功能丧失或性能明显下降轻微影响，无安全后果
O 发生频度高频（≥ 1/1000 次·年）偶发（1/10⁴ ~ 1/10⁵）罕见（≤ 1/10⁶）
D 可探测度几乎不能探测依赖巡检 / 定期测试在线监测或联锁可立即发现

RPN 判定口径：RPN ≥ 100 高风险（红）· 50–99 中风险（橙）· < 50 低风险（绿）；S ≥ 9 单独标注「必须处理」。

保护层分析（LOPA）工作区

后果分级IPL / PFD RRFSIL 定级

Layer of Protection Analysis · GB/T 32857-2025：后果分级 → 可容忍风险 → 初始事件频率 → 使能条件 / 条件修正因子 → 独立保护层 PFD → 单一 / 复合场景后果频率 → RRF 与 SIL 建议 → 风险矩阵行动要求与合规自检。本工作区已直接内嵌在 PHA 内，无需跳转。

使用方法：填写 ① 风险点信息 → ② 后果与可容忍风险 → ③ 场景与独立保护层 → 点击「计算」。 后果频率按公式（2）（3）计算，RRF 按公式（5）（6）计算；高要求模式按附录 E 计算。
标准约束：单一使能条件取值不宜低于 0.1，单一场景所有使能条件乘积不宜小于 0.01（7.5.2.1）； 单一场景所有修正因子乘积不宜小于 0.01，暴露致死率不宜小于 0.1（7.6.2.2 / 7.6.2.5）。 培训和取证、操作规程、定期的测试和检测、维修维护、警示标识 不宜作为独立保护层（7.7.1）。

    生命周期闭环

    AQ/T 3034-2022 4.2.3 要求工艺装置建设期间进行一次工艺危害分析，并每 3 年重新确认与更新；涉及变更、事故后应重新分析。建议路径：HAZID / What-If（找隐患）→ HAZOP / FMEA（查细节）→ LOPA（量化防线）→ FTA / ETA / Bow-Tie（建模推演与屏障管理）→ 建议措施闭环 → 3 年再确认。

    选型建议

    筛查阶段用 Checklist / HAZID 快速圈定重点；结构化提问用 What-If；逐单元查细节用 HAZOP（引导词 + 参数偏差）或 FMEA（失效模式 + RPN）；量化防线用 LOPA（后果频率 + IPL PFD + SIL）；需要推演因果组合与屏障成败用 FTA（演绎）/ ETA（归纳），二者组合即 Bow-Tie。方法选型不是单选题：一个 PHA 项目通常是「HAZID → What-If → HAZOP / FMEA → LOPA → FTA / ETA / Bow-Tie」的组合。
